# SMCP Website Concept

Premium, sales-focused responsive homepage concept for Sell My Commercial Property.

## Preview locally
Open `index.html` in a browser. The page is static and uses remote Unsplash imagery plus Google Fonts.

## Concept details
- Responsive desktop and mobile layout
- Seller-focused calls to action and property type overview
- Four-step acquisition process
- FAQ section and direct email enquiry CTA
- Accessible navigation toggle and reduced-motion support

## Before public use
This is a speculative design concept, not an approved production website. Replace illustrative Unsplash images and placeholder case studies with verified, approved company assets. Confirm every claim, offer timeframe, fee statement, contact detail and legal requirement with the business. The enquiry CTA opens an email client; no lead database or backend is connected.

## GitHub Pages
The included workflow publishes the repository root to GitHub Pages. In the repository, open **Settings → Pages**, set **Build and deployment → Source** to **GitHub Actions**, then check the Actions tab for deployment status.
